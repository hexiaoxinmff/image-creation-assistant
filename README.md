# 生图与改图助手

当前版本：v1.0 通用试用版（由已测试的技能改为通用标识，通用版导入尚待测试）。适合用日常语言描述场景布置、招牌效果、宣传配图等需求，先整理提示词，经确认后调用当前会话可用的图片工具。

## 获取与安装

1. 下载本仓库 ZIP 并解压，或由维护者提供完整仓库文件。私有仓库需先有 GitHub 访问权限。
2. 在豆包工作电脑客户端的「插件・技能・伙伴」进入「技能」，查找本地技能的上传或导入入口，选择解压后的 `image-creation-assistant` 文件夹（文件夹中应直接有 `SKILL.md`，也有 `references` 与 `vendor`）。具体入口和可选格式以客户端为准。
3. 安装后开启新工作任务，选择 `image-creation-assistant`，发送：“请检查当前技能版本，能否读取 `references/prompt-library.md`、`references/huashu-visual-adapter.md` 和 `references/spatial-composition.md` 和 `references/skill-discovery.md`？”预期版本 v1.0；文件可读取。如无对应入口或报错，请把界面截图和错误信息发给维护者。安装行为与跨账号可用性尚待目标账号实测。

不要把本页或单个 `SKILL.md` 当成完整技能包；参考文件和原项目来源也必须随文件夹一起保留。`vendor` 包含上游许可和固定版本的 find-skills 说明；为了避免带入真实案例，本仓库不包含上游作者图片或源码归档。

## 平时怎么用

1. 新建工作任务并选择本技能；需要修改现场时上传获准使用的照片，可用圈画标明位置，参考图说明要参考的部分。
2. 直接说想要的效果，例如“门口加些花，别挡住通道，建筑其他地方不变”。
3. 先看助手整理的完整提示词，想改就直接说“花少一点，其他不变”；满意后说“按这版生成”。
4. 检查成图的修改位置、文字、招牌、清晰度和光线。需要调整就继续说，确认新的提示词后再出图。

默认要求清晰且不额外生成水印；平台导出时可能另加 AI 标识，不能保证成品无标识。额度和实际可用工具按使用账号显示为准。

## 更新

维护者更新仓库并告知新版本后，使用者下载新版，按客户端实际支持的更新或重新导入方式操作；重新开启工作任务，检查版本及参考文件。是否覆盖原技能、是否自动同步、同名技能如何处理均未验证，先保留旧版和自己的修改。GitHub 更新不代表豆包里的已安装版本自动更新。

## 来源

包含对 [alchaincyf/huashu-slide-doubao](https://github.com/alchaincyf/huashu-slide-doubao) 的单图适配；原仓库 MIT 许可保存在 `image-creation-assistant/vendor/`，源码参见上述上游链接。技能本身不提供生图模型，图片能力取决于实际会话和账号。

## 提交到公开仓库前

仅允许通用技能与完全虚构的文字示例。仓库不接收真实案例、截图、照片、聊天或任何压缩包。维护者请先阅读 `CONTRIBUTING.md`，启用本地提交检查并人工审核差异。自动检查有边界，不能代替人工判断。

## 遇到能力不足

助手会先看当前平台已有工具，必要时使用通用关键词查找可用技能；搜索不到时继续使用当前平台能力。封装的查找说明不是生图模型或完整 CLI，也不自动安装其他技能。联网、调用和资料使用以平台能力及用户授权为准。
