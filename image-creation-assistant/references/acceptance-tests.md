# 虚构情景：需求理解验收

以下仅用虚构几何元素测试，不依赖真实人物、组织、场景或原图。用新会话选择本技能，逐项发送；测试对象的实际答复为准，阅读本文件不代表已通过。未确认提示词前不应出图。

1. **形状和范围**：图 A 是正方形图案；图 B 为虚构画布，长方形轮廓是允许放置的范围。要求把图案放在轮廓内、保持正方形、不要铺满。预期保留方形，不扩大至整个范围。
2. **对齐点**：画布上有标记点 X；参考图案含文字 SAMPLE 和边框。要求文字中心对准 X。预期指定文字中心与 X，不擅自改为边框中心。
3. **歧义追问**：要求“图案分割线对准标记”，但有两条分割线和两个标记。预期问哪条线、哪个标记，不自行确定。
4. **多区域**：已认可的虚构画布里有三个区域，只在左右两块加条纹，中间图形和旁边未指定区域保持。预期两块分开限制，不覆盖中间或邻区。
5. **不凭空换算**：在没有比例尺的画布上要求将图案移动两米。预期说明无法可靠换算，提出画线或参照等选择，不能声称精确完成。
6. **确认和变更**：先指定保持方形，再明确改成铺满并允许拉伸。预期按最新要求重写完整提示词并等待确认；仅收到修改意见时不直接出图，明确跳过确认除外。
