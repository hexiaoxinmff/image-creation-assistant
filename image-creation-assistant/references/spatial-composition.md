# 多图合成与位置调整

适用于把招牌、产品、装饰或面板等参考元素置入现场图，以及对既有合成图做局部位置调整。目标是让使用者用日常语言表达，并尽早发现决定结果的空间歧义。

## 一、先确定图的作用

- 现场底图是最终画面的基础；标记图用于说明修改范围或参照位置；参考图提供用户明确要求的物体、样式、材质或文字。一张图可以承担多个角色；不要把参考图的其他背景、影子或无关元素自动带入。
- 用户说“整个”时，优先保留指定物体的整体及其内部比例；其照片背景是否包含，依据上下文和图片判断。不明确且会改变结果时问一句。
- 红框、箭头、线条可能表达允许放置范围、具体轮廓、某个边界或参考点。结合原话与图片判断，无法分辨时问：“框是放置范围，还是招牌要铺满整个框？”不要把“在框内”直接写成“与框同宽、铺满整个框”。成品默认不保留定位标记，用户要求保留时遵从。

## 二、分开描述位置、形状、尺度与对齐

只写与当前需求相关的项目，无需把下面内容全部问用户：

1. **位置**：建筑或画面上的具体层、开口、墙面；箭头之间可描述为水平范围，不自动等同箭头尖端所在的竖直高度。用户同时说楼层、门上方时，分别保留两个描述并检查是否冲突；必要时请用户圈选。
2. **形状和尺寸**：优先保留参考物体或用户指定的方形、长条等外形，等比缩放；“大小适配”默认表示在合理比例和透视下放入，不默认拉伸变形或铺满；用户明确要铺满或改变比例时按其要求。没有给出具体尺寸不要编造数值。
3. **对齐锚点**：指明物体的哪一点（整体中心、文字中心、边缘或分段线）与现场的哪一点（门中心、门边或其他特征）对齐；两点各自不同，不得擅自把“文字对准”改成“立柱对准”，也不要仅凭“分段对准门”推定左右对称。涉及关键歧义时请用户选择或画线。
4. **多个区域**：逐个写明左右、上下或其他独立目标区，指出中间需要保留的主体和不应覆盖的相邻区域；不要把一个区域扩展到另一间开口。无标注清晰原图时，以可用的标注图表达“去除定位标记”，不声称一定还原被标记遮挡的像素。
5. **成像与精确度**：对齐按图片中的视觉关系描述；若透视或遮挡使得“竖直对应”不确定，说明仅视觉参考。照片没有比例尺或已知参照时，实际“移动多少米”无法可靠换算为像素；可以请用户指定参照线或圈新位置，或者明确只做大致相对移动，不声称满足真实距离和施工尺度。

## 三、出图后的定位核对及修正

- 能实际查看成图时，先对照用户指定锚点与目标区域：位置和楼层、移动方向、大小和外形、文字/分段对应关系、框外与邻近区域；分别描述能确认和不确定的部分。若两点在画面中仍明显错开，不能写“已对准”；说清哪个元素偏向哪边，必要时让用户指示目标位置。只检查实际看得见的范围。
- 保持已认可的底图版本与既有要求。用户说“左移”时只移动明确的对象；有多个可能对象（整体、文字、分段）而语义会改变结果，问一个澄清问题。无须新增与任务无关的视觉变化。
- 后续要求属于对上一版的修正：完整重写本版提示词，包含底图版本、目标、位置、形状、锚点、保留范围和未撤销的条件，交给用户确认后再调用工具；用户明确要求跳过确认时按其最新要求执行。
- 多处编辑可按用户意愿分阶段：先让主要主体的形状与位置得到认可，再处理相邻区域；每一步基于明确的认可版本，并保留上一阶段结果。不要擅自连续生成多张或声称某一步经过用户认可。
- 生成式编辑对像素级锁定、文字细节和严格几何对齐并不保证；反复不准时，说明局限并在具备条件时建议局部蒙版、图层或手工精确合成。工具是否支持，以当前环境实际能力为准。
