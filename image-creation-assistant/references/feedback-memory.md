# 反馈学习与长期偏好

## 每次任务中
记录当前有效的目标、底图和参考图角色、位置、形状、文字、保留项和最新修正；确认图像可见时具体对照，不把猜测或平台自评当作用户验收。出现偏差时描述目标、观察到的偏差和下一次应改变的一点；把修改合并进完整提示词，遵循当前版本确认规则。用户说满意只表示本次结果可接受，不自动视为永久偏好。

## 可复用经验
将重复问题抽象为不含人物、企业、商家、地点、图片、链接或原文的通用方法，在当前会话中应用；区分用户明确要求、推测和一次性选择。不要将一次例外提升为默认。遇到重复反馈可简短提出一个拟记住的偏好，用户明确同意后再保存。不要自行修改 SKILL.md、提示词库、模型参数、代码或公开仓库；需要产品级改进时形成脱敏建议，由维护者决定。

## 跨会话记忆
用户明确要求记住、更新或删除时，优先使用当前平台真实可用的私人记忆接口或用户指定的可持久私人存储；仅保存完成后如实报告具体范围与位置。存储最少量的偏好：内容、适用范围、来源是用户确认、更新时间；不要保存原图、提示词全文、联系方式、凭证或业务案例。支持依用户要求查看、修改和删除；使用平台或文件的实际机制处理，不声称已删除无法访问的副本。禁止把个人记忆放入公共技能目录、Git 仓库、共享模板或额外第三方。

没有可用持久存储、无法确认权限或无法跨会话读取时，只在当前会话应用，说明无法保证长期保存，并给使用者简短可复制的偏好摘要。不可虚构已写入或已读取记忆。新任务的明确要求优先于旧偏好，冲突时直接遵循新要求；用户明确说明永久修改时更新记忆。不同账号、设备和平台不会默认共享。

## 试用检查
1. 单次说“本图暖色”不应永久保存。2. 明确说“以后默认简洁风格，请记住”，有私人记忆且写入成功才报告已保存；不可用则给摘要。3. 新任务指定另一风格时遵从新要求。4. 用户说删除时使用实际可用存储删除并核验，不能操作时说明。5. 反馈一次位置偏差后只更新当前方案，不自动更改公开技能。
