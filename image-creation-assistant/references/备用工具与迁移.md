# 备用工具与迁移 v0.6

用于豆包不可用、额度不足或用户主动询问其他平台。技能负责整理可迁移提示词，不代表这些平台已经接入本技能。

1. 首先说明已知限制。账号额度、可用模型、上传图片数量、是否支持局部改图、输出规则及费用均以目标平台当时官方页面和实际账号为准；没有可靠实时证据时不报具体数字、不保证免费。客户端额度与 API 额度分开，API 可能产生费用。
2. 用户自行选择平台；若仅需要候选，可根据任务提出即梦（场景图比较）或 Canva 可画（视觉排版）的候选，是否适合、支持参考图及权益须以实际功能核实；不因为备选而主动跳出豆包，也不强制注册或购买。
3. 保留当前完整中文提示词，注明是文生图还是原图编辑，按真实附件说明：原图、定位图、材质/标识参考各是哪张；若平台图片数量或局部编辑能力不足，请用户查看界面并按其实际情况调整，不能保证不同工具生成一致。
4. 可复制提示词之后用一句话交代手动操作：将相关图片按平台支持的方式添加，粘贴提示词，检查当前模型和消耗提示，再自行生成。若平台不支持原图编辑，就说明不能等同局部改图。
5. 不执行上游项目脚本，不配置接口或上传到其他平台；用户自行上传前确认素材使用权限及相关资料使用要求。没有实际图片或结果不说“生成成功”。
